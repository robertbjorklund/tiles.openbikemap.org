# tiles.openbikemap.org

MapLibre styles and vector tile hosting for [OpenBikeMap.org](https://openbikemap.org).

This repo mirrors the role of `tiles.openskimap.org` in the OpenSkiMap stack: it serves MVT tiles and a combined basemap + bike data style for the frontend.

## Contents

| Path | Purpose |
|------|---------|
| `styles/terrain.json` | OpenFreeMap liberty basemap + `trails` / `routes` layers |
| `config.json` | [tileserver-gl](https://github.com/maptiler/tileserver-gl) configuration |
| `mbtiles/openbikemap.mbtiles` | Vector tiles (generated by `openbikedata-processor`) |
| `static/openbikemap-internal.json` | TileJSON for production CDN tile URLs |

## Prerequisites

- [Docker](https://www.docker.com/)
- Generated `openbikemap.mbtiles` from [openbikedata-processor](https://github.com/robertbjorklund/openbikedata-processor)

## Quick start

```bash
# 1. Generate tiles (from openbikedata-processor)
cd ../openbikedata-processor
BBOX='[17.9,59.32,18.05,59.36]' GENERATE_TILES=1 npm run prepare-geojson

# 2. Copy mbtiles into this repo
cd ../tiles.openbikemap.org
./scripts/sync-data.sh

# 3. Start tile server (http://localhost:8083)
docker compose up
```

Endpoints:

- Style: http://localhost:8083/styles/terrain/style.json
- TileJSON: http://localhost:8083/data/openbikemap.json
- Health: http://localhost:8083/health

For local frontend development, set `VITE_TILES_BASE_URL=http://localhost:8083` in `openbikemap.org`.

## Regenerating the style

The terrain style extends [OpenFreeMap liberty](https://tiles.openfreemap.org/styles/liberty) with bike layers:

```bash
npm run build-style
```

## Production deployment

1. Run `openbikedata-processor` globally (no `BBOX`) with `GENERATE_TILES=1`
2. Optionally extract tiles: `npm run extract-tiles data/openbikemap.mbtiles data/openbikemap`
3. Deploy `openbikemap.mbtiles` (or extracted PBFs) and this repo to your tile host
4. Point `tiles.openbikemap.org` DNS at the tileserver-gl instance
5. Update `static/openbikemap-internal.json` tile URLs if serving PBFs from a CDN

## Vector tile layers

| Source layer | Description |
|--------------|-------------|
| `trails` | Cycleways, paths, MTB trails, gravel tracks |
| `routes` | Signed bicycle route relations |

Properties match `mapboxgl_*.geojson` output from the data processor (`id`, `name`, `category`, `color`, etc.).
